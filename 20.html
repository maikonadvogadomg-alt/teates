📘 Manual do Maikon

Como usar repositório, terminal, portas e comandos, e como conferir se as coisas estão funcionando. Toque num assunto para abrir. Os comandos têm botão Copiar.

1

Palavras que aparecem toda hora

PalavraO que é, em português simples
CódigoOs arquivos de texto que fazem o app funcionar (.html, .js, .ts, .tsx, .css, .json).
Repositório (repo)Uma pasta guardada no GitHub, na internet. Guarda o código e todas as versões antigas. É o “cofre” do projeto.
GitHubO site onde ficam os repositórios. É de graça.
Commit“Salvar uma versão” no repositório, com um recado do que mudou.
Push / PullPush = mandar do seu aparelho para o GitHub. Pull = puxar do GitHub para o aparelho.
TerminalA janela preta onde se escreve comandos. No PC: “Prompt de Comando” ou “PowerShell”. No celular: Termux.
ComandoUma ordem escrita no terminal, ex.: npm install. Escreve e aperta Enter.
Node.jsPrograma gratuito que faz os apps com servidor rodarem no PC. Sem ele, o iniciar.bat não funciona.
npmVem junto com o Node. Baixa as “peças” que o projeto precisa (pasta node_modules).
Servidor (backend)A parte do app que fica “ligada” esperando pedidos: banco de dados, IA, login. O jurídico e o CodeLens têm servidor. O Mini SK e o Colador não têm: são só HTML.
PortaO “número da porta” por onde o servidor atende, ex.: 5000. O endereço fica http://localhost:5000.
localhost / 127.0.0.1“Este próprio aparelho”. Só funciona no aparelho onde o servidor está ligado.
Build“Montar a versão final” do app, mais leve, numa pasta (normalmente dist).
PWASite que se instala como app pelo Chrome (⋮ → Instalar app). Precisa de manifest.json e sw.js.
APKInstalador de app Android.
.exePrograma do Windows.
ElectronFerramenta que transforma um site em programa .exe.
Capacitor / EASFerramentas que transformam o projeto em APK. EAS é para projetos Expo.
ActionsOs “robôs” do GitHub que montam o APK ou o .exe na nuvem, de graça. Você só aperta “Run workflow”.
WorkflowA receita que o robô segue. Fica em .github/workflows/ (arquivo .yml).
Artifact (no GitHub)O resultado que o robô entrega para baixar (o APK, o zip do .exe).
.env / token / chaveSenhas. Nunca mande para ninguém nem ponha no GitHub.
DeployPublicar o app na internet (Netlify, Vercel, GitHub Pages).
2

Primeiro de tudo: salvar o código que funciona

Se um app funciona, guarde o código dele antes de mexer. Com o código guardado, nada se perde.

Da Replit

  1. Abra o projeto na Replit.
  2. No painel Files (arquivos), toque nos três pontinhos ⋮ do topo da lista.
  3. Toque em Download as zip. O zip vai para Downloads.
  4. Se não aparecer essa opção no celular, peça ao agente da Replit: “me dê o projeto inteiro como zip para baixar”.

Do GitHub

  1. Abra o repositório → botão verde Code → Download ZIP.

Onde guardar

  • No Google Drive (pasta própria, ex.: “Códigos”), num pen drive e no computador. Em dois lugares, no mínimo.
  • Coloque a data no nome: juridico-2026-10-10.zip.
3

Usar o GitHub pelo celular

Criar um repositório

  1. github.com → foto no canto → Your repositories → New.
  2. Nome sem espaço (ex.: juridico) → Private (só você vê) → Create repository.

Colocar arquivos dentro

  1. No repositório: Add file → Upload files → escolha os arquivos (extraídos, não o zip) → Commit changes.
  2. Pelo Mini SK é mais fácil: 🐙 GitHub → ele manda a pasta inteira.

Mandar o robô montar (APK / .exe)

  1. No repositório, aba Actions.
  2. Na lista da esquerda, toque no nome do workflow (ex.: “SK Editor V3 — .exe”).
  3. Botão Run workflow → Run workflow verde.
  4. Espere (5 a 15 min). ✔ verde = deu certo. ✖ vermelho = deu erro.
  5. Verde: toque na execução → desça até Artifacts → baixe.
  6. Vermelho: toque na execução → no passo com ✖ → tire print das últimas linhas vermelhas.
Não aparece “Run workflow”? O repositório não tem a pasta .github/workflows, ou ela não subiu (pastas que começam com ponto às vezes ficam para trás no upload pelo celular). O Mini SK manda essa pasta certinho.

Guardar senha no cofre (Secrets)

  1. Repositório → Settings → Secrets and variables → Actions → New repository secret.
  2. Nome (ex.: EXPO_TOKEN) e o valor. Fica trancado: nem você vê de novo.

Abrir o terminal

No computador (Windows)

  • Jeito mais fácil: abra a pasta do projeto, clique na barra de endereço lá em cima, apague, escreva cmd e Enter. Abre a janela preta já dentro da pasta.
  • Ou: botão Iniciar → escreva “cmd” → Prompt de Comando.

No celular

  • App Termux (baixe pelo F-Droid ou GitHub, a versão da Play Store é velha).

Truques que salvam

  • Seta para cima ↑ repete o último comando.
  • Ctrl + C para o que está rodando (no Termux: Volume-baixo + C).
  • Copiar no terminal do Windows: selecione e clique com o botão direito. Colar: botão direito.
  • Comando escrito errado não estraga nada, só dá aviso.

Os comandos mais importantes

Andar entre pastas

cd nome-da-pastaEntrar numa pasta.
cd ..Voltar uma pasta.
dirWindows: listar o que tem na pasta. (No Termux é ls.)
clsLimpar a tela no Windows. (No Termux: clear.)

Conferir se o Node está instalado

node -vTem que aparecer algo como v22.x. Se disser “não é reconhecido”, instale em nodejs.org (LTS).
npm -v

Ligar um projeto com servidor (jurídico, CodeLens…)

npm installBaixa as peças. Só na 1ª vez, ou quando der “Cannot find module”. Demora.
npm run devLiga em modo de teste. Mostra o endereço (ex.: http://localhost:5000).
npm run buildMonta a versão final.
npm startLiga a versão final (depois do build).
Não sabe quais comandos o projeto tem? Abra o arquivo package.json e procure a parte "scripts". Cada nome ali vira npm run NOME.

Termux (celular)

pkg update -y && pkg upgrade -yAtualizar o Termux. Faça primeiro.
pkg install -y nodejs-lts git unzipInstala Node, git e unzip.
termux-setup-storageDeixa o Termux ver a pasta Downloads (fica em ~/storage/downloads).
unzip -o ~/storage/downloads/ARQUIVO.zip -d ~/projetoExtrai um zip. Troque ARQUIVO pelo nome.

git (para quem usar no PC ou Termux)

git clone https://github.com/SEU-USUARIO/SEU-REPOBaixa um repositório inteiro.
git pullPuxa as novidades do GitHub.

Portas: como conferir se está funcionando

Quando o servidor liga, a janela preta mostra algo como serving on port 5000 ou http://localhost:5000. Esse número é a porta.

Teste 1 — o mais simples

  1. Deixe a janela preta aberta (fechou, desligou).
  2. No navegador do mesmo aparelho, escreva http://localhost:5000 (troque 5000 pelo número que apareceu).
O que apareceQuer dizer
O app abre✅ Está funcionando.
“Não é possível acessar esse site” / “Recusou a conexão”O servidor não está ligado, ou é outra porta. Olhe a janela preta.
Página brancaO servidor está ligado, mas a tela quebrou. No PC aperte F12 → aba Console → print do vermelho.
Erro 500O servidor está ligado, mas deu defeito lá dentro (quase sempre o banco de dados). O motivo aparece na janela preta.
Erro 404O servidor está ligado, mas aquele endereço não existe.

Teste 2 — quem está usando a porta (Windows)

netstat -ano | findstr :5000Se aparecer uma linha com LISTENING, alguém está usando a porta 5000. O último número da linha é o “PID” (o número do programa).
taskkill /PID 1234 /FFecha à força o programa que prendeu a porta. Troque 1234 pelo PID.

Teste 2 — no Termux

curl -I http://127.0.0.1:5000Se responder “HTTP/1.1 200” está funcionando. “Connection refused” = desligado.
Os seus jurídico-local e CodeLens-local novos já escolhem sozinhos uma porta livre e mostram o endereço na janela preta. Se já estiver aberto, ele reaproveita.

Erros comuns e o que fazer

MensagemO que fazer
'node' não é reconhecido / command not foundInstale o Node.js (nodejs.org, LTS) e abra uma janela preta nova.
Cannot find moduleRode npm install dentro da pasta do projeto.
EADDRINUSE / “address already in use”A porta está ocupada (o app já está aberto em outra janela). Feche a outra janela, ou use o Teste 2 das portas.
Aborted() / “press any key”O banco ficou travado porque a janela foi fechada no X. Na pasta dados, apague só o arquivo postmaster.pid e abra de novo. Para fechar sempre: Ctrl + C.
Erro 500 na VercelBanco incompleto ou DATABASE_URL errada. Vercel → projeto → Logs mostra o motivo.
ENOENTArquivo ou pasta não encontrado. Você está na pasta errada (use dir para ver onde está).
EACCES / “permission denied”Sem permissão. No Windows, não deixe o projeto dentro de “Arquivos de Programas”. Use Documentos.
Algo com replit ou REPL_IDSobrou peça da Replit. O 🏗️ Preparar do Mini SK tira.
“Windows protegeu o computador”Mais informações → Executar assim mesmo. Aparece em programa novo sem assinatura.
App “não instalado” / “já existe” (APK)Desinstale o antigo, ou troque o nome do pacote (ex.: com.maikon.app2).
npm ERR! no meio do installRode de novo. Se repetir, apague a pasta node_modules e rode npm install.

Transformar em app: PWA, APK ou .exe

PWA (o mais fácil, de graça)

  1. Precisa ter index.html, manifest.json e sw.js (o Mini SK cria).
  2. Abra app.netlify.com/drop e arraste a pasta (ou o zip).
  3. Abra o endereço no Chrome → ⋮ → Instalar app.

Só serve para app sem servidor (HTML puro). App com servidor precisa da Vercel ou do PC ligado.

APK

  • Projeto HTML: Mini SK → 📦 APK.
  • Projeto Expo: Caça-Bug → Consertar para o EAS → Mini SK → ☁️ EAS.
  • Projeto com Capacitor: sobe no GitHub → Actions → Run workflow → Artifacts.

.exe (programa do Windows)

  1. O projeto precisa ter a pasta electron e o arquivo .github/workflows/desktop-exe.yml (o 🏗️ Preparar do Mini SK cria os dois).
  2. Sobe no GitHub → Actions → Run workflow.
  3. Verde → Artifacts → baixa um zip → extrai → abre o .exe.
.exe que fecha ou fica branco: se o app tem servidor (banco, IA), o .exe precisa levar o servidor junto. Para o jurídico e o CodeLens, o caminho mais certo é o iniciar.bat com o Node instalado.

Como pedir ajuda para qualquer IA (e ela entender)

Mande sempre estas 5 coisas:

  1. Qual app e qual versão (o nome do arquivo).
  2. Como abriu: site, app instalado, iniciar.bat, Termux, APK.
  3. O que fez, passo a passo.
  4. O que esperava e o que aconteceu.
  5. Print do erro: janela preta (últimas linhas), F12 Console, ou passo vermelho do GitHub. Nunca com senha aparecendo.

Modelo para copiar:

App: ____ (versão ____). Abri pelo ____. Fiz: ____. Esperava: ____. Aconteceu: ____. Segue o print do erro. Me responda em português simples, um passo por vez, e me diga só o que eu preciso tocar.
Peça um passo por vez. Quando a IA mandar 10 arquivos de uma vez, peça: “junte tudo num zip só e me diga só onde eu coloco”.
10

Segurança

  • Nunca mande para ninguém, nem em print: tokens (GitHub, Expo), chaves de IA, DATABASE_URL, arquivos .env, .pem, .key, .keystore.
  • Senha só vai: dentro do próprio app (🔑), no cofre do GitHub (Secrets) ou nas variáveis da Vercel.
  • Vazou? Apague a chave no site e crie outra.
  • SQL que começa com DROP TABLE apaga dados.
  • Repositório com código de cliente: sempre Private.
11

Cartão rápido (o resumo de tudo)

  1. Funciona? Guarde o código em dois lugares antes de mexer.
  2. App com servidor no PC: Node instalado → pasta extraída → iniciar.bat (ou npm install e npm run dev).
  3. Conferir: navegador em http://localhost:PORTA.
  4. Erro: leia a janela preta, tire print das últimas linhas.
  5. Fechar: Ctrl + C, nunca no X.
  6. App sem servidor: Netlify Drop → Instalar app.
  7. APK/.exe: GitHub → Actions → Run workflow → Artifacts.
