❌ Este navegador não consegue mexer em pastas. Abra este arquivo no Google Chrome ou no Microsoft Edge, no computador.

Como funciona

  1. Você escolhe a pasta do computador (ex.: Documentos, Clientes).
  2. Você escolhe onde guardar no HD (crie uma pasta, ex.: "Backup PC"). Lá dentro ele cria uma pasta com o mesmo nome da pasta copiada, então dá para guardar várias pastas no mesmo lugar sem misturar.
  3. Toca em Copiar. Na 1ª vez copia tudo; das outras vezes, só o que é novo ou mudou.
🛡️ Esta página nunca apaga nada: nem no computador, nem no HD. Ela só copia.

Dúvidas comuns
  • "Não é possível abrir esta pasta porque ela contém arquivos do sistema": o Chrome não deixa escolher pastas como o disco C: inteiro ou a pasta do usuário. Escolha uma pasta de dentro (Documentos, Imagens, Clientes…).
  • O HD não aparece: veja se ele está em "Este Computador". Se não estiver, troque a porta USB.
  • Onde fica o registro do que já foi copiado? Num arquivo .backup-registro.json dentro da pasta do HD. Não apague, senão ele copia tudo de novo (sem estragar nada, só demora).
  • Para recuperar: é só abrir a pasta no HD. Os arquivos estão lá normais, do mesmo jeito do computador.
