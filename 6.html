🦙 Guia do Ollama

A IA que roda dentro do seu próprio computador (ou celular), sem internet e de graça. Toque num assunto para abrir. Os comandos têm botão Copiar.

Em uma frase: o Ollama é o "aparelho". Os modelos (llama, phi, qwen, gemma…) são os "cérebros" que você baixa para dentro dele. Cada cérebro fica guardado até você apagar.
1

Ver quais cérebros você tem

Abra um terminal (veja a parte 6) e digite:

ollama listMostra todos os modelos baixados, o tamanho de cada um e quando foram baixados.

Você disse que apareceram 5. É normal: cada vez que se pede um modelo que não existe, ele baixa. Cada um ocupa de 1 a 5 GB no disco.

ollama psMostra qual está "ligado" na memória agora (o que está respondendo).
2

Qual cérebro fala português

Os que costumam responder bem em português:

ModeloTamanhoBom para
phi4-mini~2,5 GBÉ o da Microsoft (o que respondeu em português para você). Bom equilíbrio.
qwen2.5:3b~2 GBMuito bom em português, rápido no PC.
gemma3:4b~3 GBDo Google. Bom em português; um pouco mais pesado.
gemma3:1b~800 MBLeve. O melhor para celular ou PC fraco (responde mais simples).
llama3.2~2 GBTende a responder em inglês se não mandar falar português.

Para baixar um deles (exemplo):

ollama pull qwen2.5:3b
Dica: fique com um ou dois que falem português e apague o resto (parte 4). Sobra espaço e você não se confunde.
3

Fazer ele responder sempre em português

Conversando no terminal

ollama run phi4-miniLiga o modelo e abre a conversa. Troque "phi4-mini" pelo nome que aparece no "ollama list".

Logo depois que ele abrir (aparece >>>), cole isto e Enter:

/set system Responda sempre em português do Brasil, de forma simples.

Agora é só escrever a pergunta e Enter. Para sair da conversa:

/bye

No Mini SK para PC

O Mini SK já manda a IA falar português. Se ainda vier em inglês, é o modelo (troque para phi4-mini ou qwen2.5:3b).

4

Apagar os que não usa (liberar espaço)

ollama rm llama3.2Apaga o modelo do disco. Troque pelo nome que você quer apagar (veja no "ollama list").
ollama stop phi4-miniNão apaga: só tira da memória (o PC fica mais leve). Ele volta quando você usar de novo.
5

Usar dentro do Mini SK (no computador)

  1. Deixe o Ollama aberto: o ícone da lhama 🦙 perto do relógio do Windows. Se não estiver, abra "Ollama" no menu Iniciar. Não feche a janela preta se ele estiver rodando nela.
  2. No Mini SK: 🤖 IA → ⚙️ Chaves → ＋ → no tipo, escolha Ollama (no seu PC, grátis — sem chave).
  3. Toque em Buscar modelos e escolha o que fala português (ex.: phi4-mini).
  4. Mande "oi" e espere: a 1ª resposta demora de 1 a 3 minutos (ele carrega o cérebro na memória). As próximas são bem mais rápidas.
Se não responder: no terminal, rode ollama ps. Se não aparecer nada e o "ollama list" funcionar, o Ollama está ligado — é só esperar a 1ª carga. Se der erro de conexão, o Ollama está fechado: abra de novo.
6

Onde digitar os comandos (terminal)

No computador — jeito mais fácil

  1. Aperte a tecla Windows, escreva cmd e Enter. Abre a janela preta do Windows.
  2. Cole o comando (botão direito do mouse cola) e Enter.

No computador — dentro do Mini SK

  1. Atualize para a versão 15/10-c (o terminal ficou grande).
  2. Botão 💻 Terminal PC → ⛶ Tela cheia. Escreva o comando e Enter.
O terminal do Mini SK serve bem para ollama list, ollama pull, ollama rm, npm, git. Para conversar (ollama run), use a janela preta do Windows ou a 🤖 IA do Mini SK.
7

No celular (Termux): ele fica ou vai embora?

Fica. O modelo que você baixou está guardado no celular, dentro do Termux, até você apagar. Ele só funciona enquanto o Termux está aberto com o Ollama ligado.

Para usar de novo, no Termux:

ollama serve > /dev/null 2>&1 &Liga o Ollama "por trás" (só uma vez cada vez que abrir o Termux).
ollama list
ollama run gemma3:1bTroque pelo nome que aparecer no list. Depois use o /set system da parte 3 para falar português.
Sinceramente: no celular ele é muito lento (você viu: quase uma hora para três frases), esquenta e gasta bateria. Use só para testar. No dia a dia do celular, a IA pela internet (Gemini grátis) é muito melhor. Para apagar e liberar espaço: ollama rm nome-do-modelo.
