🧰 Kit do Maikon para o Replit

Um arquivo só (kit-replit.cjs, 13 KB). Roda no Shell do Replit, não apaga nada e faz: 📋 relatório, 📦 pacote limpo do projeto, 🌐 pacote dos sites montados e 🔨 montar um app.

Como usar no Replit
  1. Abra o projeto no Replit. Na lista de arquivos (Files), toque nos 3 pontinhos ⋮ → Upload file → escolha o kit-replit.cjs que você salvou.
    (Ou: crie um arquivo novo chamado kit-replit.cjs e cole o código copiado.)
  2. Abra a aba Shell e escreva: node kit-replit.cjs
  3. Ele pergunta o número. Para fazer tudo de uma vez: 5.
  4. Os arquivos aparecem na pasta _kit-saida. Toque nos 3 pontinhos de cada um → Download.
  5. O PACOTE-LIMPO você abre no Preparador Universal (para virar .exe/APK) ou no Mini SK. O RELATORIO você me manda aqui.
Para fazer em vários projetos
  • Repita os passos em cada projeto (Repl). É sempre o mesmo arquivo.
  • Atalho: node kit-replit.cjs 5 já faz tudo sem perguntar.
